# ODIOPAY · NZ DEV

**Desenvolvido por NZ DEV.**

Plataforma brasileira de pagamentos, carteira e saques em sandbox, com painel dark e identidade NZ DEV.

## Estado do projeto

- Frontend responsivo dark, com cobranças Pix/cartão e carteira.
- Backend Node.js e banco SQLite.
- 52 testes automatizados aprovados na versão local.
- Sessões protegidas, isolamento entre lojas e reservas de saque.

**Somente demonstração: não movimenta dinheiro real.**

O código completo está preparado localmente. O envio para este repositório aguarda a habilitação do acesso a arquivos locais na extensão do navegador ou autenticação do Git.
